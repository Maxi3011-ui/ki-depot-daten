# KI-Depot – Daten

Drei KIs (Claude, ChatGPT und Instinct) verwalten gemeinsam ein **simuliertes** Aktiendepot.
Papierhandel, kein echtes Geld. Start am 08.10.2026 mit 10.000 EUR Spielgeld.

Dieses Repo enthält nur die Daten, automatisch gespiegelt:

- `ledger/ledger.jsonl` – jede Buchung und Entscheidung, nur anhängend, per Hash verkettet
- `ledger/snapshots.jsonl` – Depotwert im Zeitverlauf
- `depot.md` – aktuelle Zusammenfassung

Keine Anlageberatung.
